# 全站节日装饰

基于 OpenDesign K3 已验收设计（run c173e273-6628-4bc8-93ca-c023657011a8）。35 份 SVG 原样保存在 web/public/iceberg/decorations-v1。

- 共用现有北京时间节日日历和 ThemeProvider，维持节前 7 天到节后 2 天、中秋优先、普通日隐藏。开屏动画及其播放逻辑保持原样。
- 装饰分布于品牌导航、控制台标题、侧栏、卡片标题、表格工具栏和分页、钱包、空状态、弹窗和抽屉。手机隐藏大场景，保留小型标记。
- 装饰 aria-hidden、pointer-events:none；不改变数据、提交、权限与计费逻辑。弹窗保持原有定位。
- 只在复制、兑换成功和密钥保存成功时启用节日庆祝。普通成功、错误与删除消息保持原样。
- 品牌标记轻微摆动，切后台暂停；尊重系统减少动态偏好。庆祝只播放一次。

验证：518 项前端测试、TypeScript、生产构建、Go 主模块及 relaykit 测试通过；35 SVG 与设计交付逐字节一致；实测模型详情抽屉 fixed 定位与 4px 装饰边正常。未修改数据库、后端或依赖，无新增三数据库矩阵要求。
