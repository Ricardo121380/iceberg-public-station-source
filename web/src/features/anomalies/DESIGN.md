# 异常提醒控制

Operate 模式，继承现有管理后台，不改变全局品牌、头部和导航系统。

- 使用 SectionPageLayout 的既有标题和滚动容器。
- 主体为异常事件、提醒规则、处理记录三个标签页；不另设多级侧边栏。
- 筛选字段有独立可访问标签，按用户、类型、处理状态筛选；移动端自然换行。
- 事件使用分隔线列表；待关注使用既有 destructive Badge，普通观察使用 secondary。
- 规则表单桌面两列、移动端一列，原生数值校验及服务端范围校验一致。
- 模型长文本可换行；时间、计数、阈值是主要诊断信息。
- 采集范围与保留说明折叠呈现，常显“仅观察，不自动暂停”。
- 加载、错误重试、空结果、确认冲突、保存状态均有文字反馈。
